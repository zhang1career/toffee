# 海浪声方案说明

## 一、程序化海浪：推荐参数

源码中的海浪相关常量（`backgroundSoundAdapter.ts`）已按推荐范围设置，可根据听感微调：

| 参数 | 推荐范围 | 当前默认 | 说明 |
|------|----------|----------|------|
| `OCEAN_LOOP_LENGTH` | 4～6 秒 | 5 | 循环时长，越长重复感越弱 |
| `OCEAN_WAVES_PER_LOOP` | 0.2～0.4 | 0.28 | 每段循环内波数，越小波间隔越长 |
| `OCEAN_ENVELOPE_SOFTNESS` | 0.55～0.75 | 0.65 | 包络舒缓度，越小每波越柔和 |
| `OCEAN_LOWPASS` | 0.86～0.90 | 0.88 | 低通系数，略低更厚更“远” |
| `OCEAN_LFO_FREQ` | 0.015～0.03 Hz | 0.022 | 整体起伏速度 |
| `OCEAN_LFO_GAIN` | 0.05～0.10 | 0.065 | 整体起伏幅度 |

当前实现：**粉红噪声** + 单极点低通 + 舒缓包络 + 慢速 LFO，无录音依赖、可调参数。

## 二、更逼真的方案：录音循环

程序化合成在真实度上有上限，若要更接近真实海浪，建议使用**预录音循环**。

### 1. 使用适配器提供的 URL 接口（推荐）

Web 端在播放海浪前调用：

```ts
import { setOceanAudioUrl } from '@zhang1career/audio/web/backgroundSoundAdapter';

// 设置海浪录音 URL（MP3 或 WAV），解码在后台进行
setOceanAudioUrl('https://your-cdn.com/audio/ocean-waves-loop.mp3');

// 之后选择「海浪」时会优先播放该录音；解码失败或未设置则回退程序化
// 取消录音、仅用程序化：
setOceanAudioUrl(null);
```

- 录音建议：30 秒～2 分钟、无缝循环、采样率 44.1kHz/48kHz、立体声。
- 若需无版权素材，可选用 Freesound、Pixabay 等站点的 “ocean waves loop” 并做无缝剪辑。

### 2. 自托管录音文件

将海浪循环放在项目或 CDN（如 `public/audio/ocean-loop.mp3`），在应用初始化时调用 `setOceanAudioUrl` 传入该 URL。

### 3. 其他思路（未在包内实现）

- **长录音 + 随机切片**：用较长录音，每次随机起播点，减少循环感。
- **多层合成**：程序化“底噪” + 录音“浪花/撞击”叠加。
- **物理/粒子合成**：基于水面或粒子模型合成（实现复杂，适合游戏/高端应用）。

## 三、小结

| 方案 | 真实度 | 资源 | 适用场景 |
|------|--------|------|----------|
| 程序化（当前） | 中等 | 无文件、可调参 | 默认、无网络/无资源 |
| 录音 URL（setOceanAudioUrl） | 高 | 需托管 MP3/WAV | 追求逼真、可接受少量资源 |
| 长录音 + 随机起播 | 高 | 较大文件 | 可接受体积时进一步弱化循环感 |
